# Weather Advisor

Android-приложение на Kotlin для получения текущей погоды и генерации советов пользователю.

## Функционал

- Локальный поиск города по базе GeoNames
- Получение координат выбранного города
- Получение актуальной погоды через OpenWeather API
- Получение погоды по местоположению пользователя
- Генерация советов: зонт, шапка, сильный ветер, комфортность прогулки

## Стек

- Kotlin
- Android
- Jetpack Compose
- Room
- Retrofit
- OpenWeather API
- GeoNames dataset
