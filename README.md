# Weather Advisor

**Weather Advisor** — Android-приложение на Kotlin для просмотра текущей погоды и генерации практических советов пользователю.

Проект выполнен для университетской практики по варианту **«Симулятор погоды / генератор советов»**. Вместо случайной генерации в приложении используется реальная текущая погода через OpenWeather API, локальная база городов GeoNames и получение погоды по местоположению пользователя.

## Возможности

- Локальный поиск города по базе GeoNames
- Приоритет российских городов в результатах поиска
- Получение координат выбранного города
- Получение текущей погоды через OpenWeather API
- Получение погоды по местоположению пользователя
- Вывод температуры, ощущаемой температуры, ветра, дождя и снега
- Генерация советов:
    - брать ли зонт
    - нужна ли шапка
    - стоит ли опасаться сильного ветра
    - какую одежду лучше выбрать
- Оценка комфортности погоды по шкале от 0 до 100

## Как работает приложение

1. Пользователь вводит название города.
2. Приложение ищет город в локальной SQLite-базе, созданной на основе GeoNames.
3. После выбора города приложение получает его координаты.
4. По координатам отправляется запрос в OpenWeather.
5. Полученные погодные данные обрабатываются генератором советов.
6. Пользователь видит текущую погоду, оценку комфортности и рекомендации.

Также пользователь может нажать кнопку **«Погода по моему местоположению»**. В этом случае приложение запрашивает разрешение на геолокацию, получает координаты устройства и загружает погоду для текущего местоположения.

## Локальная база городов
Для поиска городов используется заранее подготовленная база cities.db, расположенная в:
```
app/src/main/assets/database/cities.db
```
База создается скриптом:
```
tools/build_geonames_db.py
```
Источник данных — открытые дампы GeoNames. Благодаря локальной базе поиск не зависит от сетевых запросов и не расходует квоты внешнего API.

## Настройка OpenWeather API
Для работы погоды нужен API-ключ OpenWeather.
В корне проекта необходимо создать или открыть файл:
```
local.properties
```
И добавить строку:
```
OPENWEATHER_API_KEY=your_api_key_here
```
Файл `local.properties` не должен попадать в Git.
## Разрешения Android
Приложение использует следующие разрешения:
```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
```

`INTERNET` нужен для загрузки погоды, а разрешения геолокации — для функции погоды по текущему местоположению.
